# Dhananjay Choudhary — Portfolio

Responsive personal portfolio for a Computer Science student focused on cybersecurity and network infrastructure.

## Features
- About, education, skills, certifications, projects, contact, and chatbot sections
- Search projects by title or technology
- Light/dark theme toggle with saved preference
- Responsive layouts and accessible navigation
- Four project repository links and [GitHub profile](https://github.com/dhananjaychoudhary-afk)
- Chat interface ready to connect to a same-origin `/api/chat` endpoint

## Technologies
HTML, CSS, and JavaScript. Chatbot API provider is pending; API integration is intentionally on hold.

## Run locally
Open `index.html` in a browser. Search and theme switching work locally. Chat responses require a server API route and a secret key stored in deployment environment variables.
